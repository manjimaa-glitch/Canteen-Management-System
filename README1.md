# 🍽️ Canteen Management System

A desktop-based canteen management application developed using Java Swing and MySQL.

## ✨ Features

- View food items and prices
- Add, update, and delete food items
- Manage food availability
- Place customer orders
- Calculate bills and generate order IDs
- View order history and order details
- Generate sales summaries
- Graphical user interface using Java Swing

## 🛠️ Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- MySQL Connector/J

## 🗄️ Database

The application uses MySQL to store food items, orders, and order details.

## ▶️ How to Run

1. Install Java and MySQL.
2. Create the required database and tables.
3. Configure the MySQL connection using the `CANTEEN_DB_PASSWORD` environment variable.
4. Compile the Java files with the MySQL Connector/J library.
5. Run the `CanteenGUI` class.
